식품 전문가를 구했더니

배우·콘텐츠·유통까지 갖췄다고 자신하던 앤써가 식품 전문가 최대표를 찾아가지만, 정작 팔 상품이 없다는 걸 들키고 주방으로 끌려간다.

줄거리

  1. 앤써와 김승수는 출연·콘텐츠·유통 카드를 들고 최대표를 찾아가지만, 최대표는 "망하기 딱 좋게 생겼네"라며 음식을 책임질 사람이 없다고 짚는다.
  2. 김승수의 요리 실력을 내세웠다가 최대표의 화려한 경력 앞에 바로 수긍한 두 사람은 도움을 청하고, 바쁘다는 최대표에게 앤써가 본업인 마케팅으로 돕겠다고 제안해 손을 잡는다.
  3. 드림팀이 완성된 듯했지만 사업안 다음 장은 비어 있고, 최대표는 두 사람에게 앞치마를 건네며 주방부터 가자고 한다.

웃음 포인트

  • 김승수 머리 위에 '요리 대회 우승자' 타이틀과 왕관이 뜨지만, 최대표의 경력 타이틀 네 개가 쾅쾅 쌓이자 바로 부서진다.
  • "제가 도와드릴게요"로 멋지게 성사시킨 뒤, 사업안 다음 장이 텅 비어 있다.
  • 김승수는 앞치마를 자연스럽게 받아 입는데, 앤써만 "저도요? 전 요리 못하는데요?" 하며 앉아서 당황한다.

엔딩

앤써가 앞치마를 들고 터덜터덜 주방으로 따라가며 "열심히 해야겠네요… 그쵸?" 하고, 프리퀄이 끝나며 본편으로 이어진다.

인물별 흐름

  • 앤써다 갖췄다는 자신감 → 일침에 당황 → 본업으로 반격해 성사 → 빈 종이에 머쓱 → 요리까지 떠맡아 체념
  • 김승수함께 든든한 기대 → 요리 자신감 → 최대표 경력에 바로 수긍 → 앤써를 이끌며 주방으로
  • 최대표무심한 일침 → 바쁘다며 거절 → 마케팅 제안에 관심 → 손 내밀고 주방으로 데려감
