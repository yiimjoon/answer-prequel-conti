# 사업안 (4편 소품)

버전이 여러 개다. 4편에서 실제로 쓰는 건 **사업 소개서(요약본)** 와 **정식 사업안(한글 보고서형)** 두 가지다. 모두 A4 2장(1장 본문 + 2장 백지)이고, PDF를 그대로 인쇄하면 된다.

| 파일 | 모양 | 참고 그림 |
|---|---|---|
| `business-plan-hwp.pdf` | **정식 사업안 (한글 보고서형)**: 앤써가 E4-22/23 에서 최대표 쪽으로 미는 서류. 넘기면 2장이 백지 | E4-22/23, E4-24, E4-37/38 |
| `business-plan-summary.pdf` | **사업 소개서 (요약본 1장)**: 앤써가 미팅 전에 미리 보낸 서류. 최대표가 처음부터 들고 본다 | E4-08, E4-10, E4-12, '상품' 적기 |
| `business-plan-photo.pdf` | **사진형**: 제목 아래 흑백 도시 사진 + 본문 | E4-22 (사업안 밀기) |
| `business-plan-blank.pdf` | **빈칸형**: 가운데 '사업안' 제목 + 큰 빈 테두리 | E4-12 (빈 곳 톡톡) |
| `business-plan.pdf` | 본문형: 사진 없이 본문만 | — |

`*.html`은 고칠 때 쓰는 원본(스타일은 `plan.css`), `preview-*.png`는 1장 미리보기다.
사진형의 도시 사진은 실제 사진이 아니라 흑백 사진처럼 그린 그래픽(`skyline.svg`)이다. 실사로 바꾸려면 `business-plan-photo.html`의 `skyline.svg`를 다른 이미지 파일로 바꾸면 된다.

## 본문형·사진형 1장 구성
| 부분 | 내용 | 쓰이는 컷 |
|---|---|---|
| 01 사업 구조 · 02 목표 333 · 03 팀 구성 | 본문 | E4-08 첫 일침, E4-22/23 사업안 밀기 |
| 팀 구성 오른쪽 아래 빈 칸 | 일부러 비워 둔 네 번째 칸 | E4-10/12 "음식은 누가 책임져?" 톡톡, 최대표가 '상품'이라고 적는 칸 |
| 2장 | 완전 백지 | E4-37/38 넘기면 텅 빈 다음 장 |

- 판매 상품은 어디에도 적혀 있지 않다. 1장 맨 아래에 `다음 장 04 판매 상품 →`만 있어서, 넘기면 빈 종이가 나온다.
- 팀 구성 칸 배치(위왼쪽 출연 / 위오른쪽 콘텐츠 / 아래왼쪽 유통 / 아래오른쪽 빈 칸)는 카드 탑뷰(E4-06, E4-35)와 같다.

## 빈칸형
- 1장은 제목과 큰 테두리(약 174 × 218mm)뿐이다. 최대표가 테두리 안 빈 곳을 톡톡 치고 '상품'을 적는다.
- 카드를 사업안 위에 놓고 찍는다면 이 테두리 안에 2×2로 놓으면 된다.

## 인쇄·촬영 메모
- 120g 이상 무광지 추천: 조명 반사가 덜하고 '상품'을 마커로 써도 비치지 않는다.
- 왼쪽 위 한 곳만 스테이플러로 찍어야 E4-37에서 한 장 넘기기 편하다.
- '상품'을 적는 테이크가 여러 번이면 1장을 넉넉히 뽑아 둔다.

## 한글 보고서형
한국 회사·관공서에서 한글로 만든 보고서처럼 보이게 했다.
- 제목 상자(위아래 굵은 선 + 연한 음영), 오른쪽에 날짜·담당, [보고 요지] 상자
- Ⅰ 추진 배경 · Ⅱ 사업 개요 · Ⅲ 추진 목표(333 표) · Ⅳ 추진 체계 · Ⅴ 판매 상품
- 항목은 □ → ○ → - 개조식("~함", "~하고자 함"), 표는 회색 머리행, 쪽 번호는 아래 가운데 `- 1 -`
- Ⅳ 추진 체계도의 네 번째 상자는 비워 둔다. 최대표가 톡톡 치고 '상품'이라고 적는 칸이다.
- Ⅴ 판매 상품은 "다음 쪽 참조"뿐이고 2장은 백지다.

글꼴(`hwp.css`): 제목·대제목 HY헤드라인M, 본문 HY신명조, 표 머리·날짜 HY중고딕, 강조 HY견고딕.
휴먼명조가 깔린 PC 에서는 본문이 휴먼명조로 바뀐다. 지금 PDF 는 한컴오피스가 깔린 PC 에서 뽑아서 한컴 글꼴이 그대로 들어가 있다.
한컴 글꼴이 없는 PC 에서 HTML 을 다시 PDF 로 뽑으면 바탕·돋움으로 바뀌니, 고칠 때는 한컴오피스가 있는 PC 에서 뽑는다.

## 4편에서 두 서류를 나눈 이유
대본에서 최대표는 처음부터 사업안을 보며 "망하기 딱 좋게 생겼네"라고 하는데, 중간(E4-22/23)에 앤써가 또 사업안을 민다.
같은 서류가 두 번 나오지 않도록 나눴다.
- 처음 최대표가 들고 있는 것 = **사업 소개서(요약본 1장)**. 팀 구성 오른쪽 아래 빈 칸을 톡톡 치고 '상품'이라고 적는 것도 이 종이다.
- 앤써가 "대표님, 저희 사업 좀 도와주세요!" 하며 미는 것 = **정식 사업안(한글 보고서형)**. E4-37/38 에서 최대표가 넘기면 백지가 나오는 것도 이 서류다.
- 두 서류는 겉모습이 확 달라(세련된 소개서 / 딱딱한 한글 보고서) 화면에서도 구분된다.
