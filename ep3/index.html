콘텐츠의 힘

앤써가 뭐든 가능하다는 콘텐츠 전문가 이정환을 영입하지만, 이정환은 주인공 김승수를 모른다.

줄거리

  1. 식품 사업 콘텐츠에서 막힌 앤써가 콘텐츠 전문가 이정환(라이언)을 찾아간다.
  2. 무엇을 물어도 '가능하죠'라던 이정환은 주인공이 김승수라는 말에 '누구요?'라고 되묻는다.
  3. 문 뒤에서 김승수가 등장해 어색하게 수습되고, 셋은 대박을 확신하며 신나게 떠든다.

웃음 포인트

  • 같은 미소, 같은 박자로 반복되는 '가능하죠'와 '가능' 도장
  • 김승수 대표작을 늘어놓을수록 더 모르는 이정환, 엉뚱한 작품까지 등장
  • 문 뒤에서 다 듣고 있던 김승수의 '모르시는것 같은대…?'

엔딩

휴대폰으로 셋을 지켜보던 최대표의 한마디: '망하기 딱 좋게 생겼네.'

인물별 흐름

  • 앤써난처함 → 의기양양 → 머쓱함 → 들뜬 설레발
  • 김승수단호한 조언 → 담담한 확인 → 장난스러운 여유 → 설레발
  • 이정환여유 만만 → 멍함 → 다급한 수습 → 설레발
  • 최대표무심하게 지켜보다 일침
